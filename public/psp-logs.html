How to use it
Previous work: add your major programming tasks and assignments as Previous work jobs, log the actual time in the Daily Time Logs, and enter any estimates you still have (leave the rest blank).
New project (Student Grade Management System): add the standard jobs, estimate time and expected units before you start each job, log time as you work, then record actual units when the job is done. The To Date totals update by themselves.
